## Especificações

- **Formato**: PNG com transparência (fundo transparente)
- **Tamanho recomendado**: 512x512px ou similar (quadrado)
- **Resolução**: Suficiente para telas de alta densidade (2x, 3x)
- **Fundo**: Transparente ou branco (preferência por transparente)

## Como Baixar do Wikimedia

1. Acesse o link da logo desejada
2. Clique em "Download" no lado direito
3. Escolha uma resolução adequada (ex: 512px)
4. Salve com o nome correto (ex: `nubank.png`)
5. Coloque nesta pasta

## Observações

- Se uma logo não estiver disponível, o app usará automaticamente um ícone colorido com a inicial do banco
- Logos com fundo transparente ficam melhores visualmente
- Após adicionar/atualizar logos, reinicie o servidor Metro Bundler do Expo
